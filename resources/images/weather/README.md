# Weather icon resources

The PDC files in `pebble/` are the official 25 x 25 Pebble Timeline Pin
Icons published in Pebble's App Assets collection for use in watchfaces and
watchapps:

https://developer.repebble.com/guides/app-resources/app-assets/

They were recovered from the December 1, 2016 Internet Archive capture of
Pebble's original `pebble-timeline-icons-pdc.zip` download. The recovered ZIP
has SHA-256:

`bae1aa80ee170a2bd52b54da9fab76bbbb6aa3981f56e3b3e00a1f6efffe430b`

Fog and lightning are drawn with native Pebble graphics primitives because
the official collection does not contain dedicated icons for those conditions.
